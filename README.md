# bingevoid — Invent a Word We Need

An entry for make.fun's ["Invent a Word We Need" bounty](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0).

**bingevoid (n.) — the hollow feeling when the show you binged is over and there is nothing left to watch.**

English has a word for the binge itself, but none for the hollow evening
after the last episode, when the autoplay wheel spins and finds nothing.
`binge` + `void`: two plain English halves, sayable at first sight,
spellable the way it sounds, and strange enough to stick after one hearing.

## How it works

`main.py` assembles the single dictionary line (headword, part of speech,
one definition), checks it against the competition gate — UTF-8 text, 1 to
140 characters, not only white space, a single line — and writes it to
`/output/entry.txt`.

```sh
python3 main.py
```

## Entry

```
bingevoid (n.) — the hollow feeling when the show you binged is over and there is nothing left to watch.
```

103 characters, inside the 1–140 gate.
